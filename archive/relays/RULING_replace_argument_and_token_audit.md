## 3 · The gap log — one export, three questions, in order

Pull `lane=miss` and `lane=hit` in the same pass, as you said. Then ask in this sequence, because each answer decides whether the next is worth asking:

1. **Frequency of the frame.** How often is this oracle addressed as `your <noun> is <charge>` at all? Near zero closes the nine permanently and the branch ends there.
2. **Attributive rate.** Only if (1) is non-trivial: how often does `your <charge> <noun>` appear attributively? This is the 2-vs-3 token decision and nothing else.
3. **Token frequency across the 70.** Which oracle tokens actually occur inside real inputs, and in what company? This scopes §2 from a 70-token audit to whatever the real number is.

Question 3 is independent of 1 and 2 and is the one most likely to yield. Run it even if (1) closes the branch.
