Chat

Open channel on libera.chat — #wuld-ink. Pick a nickname, click Start, talk. No account required for read-along; if you want to keep the same handle across visits, register it with NickServ once and it is yours.

House rules — informal

Disagreement is welcome. Bad faith is not. Trolling, slurs, harassment, and grooming attempts are removed without explanation. Spam vanishes on sight.

This is not a support channel and not a therapy channel. If you are in crisis, please call or text 988 (US Suicide & Crisis Lifeline) or your local equivalent.

Message board

Leave a message

A quick, public note — for me or anyone reading. Anonymous is fine; add a name if you want it attributed. Email is optional and private: I am the only one who sees it, and only so I can reply. The house rules above apply.

    Prefer live chat?

    The board above is for quick asynchronous notes. For real-time conversation during rare live events, the IRC channel is below.

    Open — libera webchat Open #wuld-ink → Libera’s own web client. Pick a nick, click Start, talk. No account required for read-along.

    Connect from an IRC client instead

    Server: irc.libera.chat:6697 (TLS) · Channel: #wuld-ink

    Any IRC client works — HexChat, mIRC, irssi, Quassel, WeeChat, KVIrc, Konversation. Point at the server above and /join #wuld-ink. The webchat options above need no install; the IRC-client route is for people who prefer it.
